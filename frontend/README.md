# FoodMatch Frontend

Interface de usuário para o aplicativo FoodMatch, desenvolvido com React.

## Funcionalidades

- Cadastro e login de usuários
- Dashboard com recomendações personalizadas
- Visualização de matches entre alimentos e bebidas
- Gerenciamento de receitas favoritas
- Carrinho de compras

## Tecnologias

- React
- React Router
- Axios para comunicação com a API
- Styled Components para estilização
- Context API para gerenciamento de estado

## Instalação

```bash
npm install
npm start
```

## Estrutura do Projeto

- `/src/components` - Componentes reutilizáveis
- `/src/pages` - Páginas da aplicação
- `/src/services` - Serviços para comunicação com a API
- `/src/contexts` - Contextos para gerenciamento de estado
- `/src/styles` - Estilos globais e temas
